# تشغيل نسخة وسيطك الأولية

## المتطلبات
- Node.js إصدار 22.13 أو أحدث.
- تشغيل الأوامر من داخل مجلد `wasitak-next`.

## التشغيل محليًا
```bash
npm start
```
ثم افتح المنفذ 3000 في بيئة التطوير.

## ما الذي تعمل عليه النسخة؟
- صفحة عربية متوافقة مع الهاتف.
- تصنيف الإعلان إلى سكن أو وظائف.
- استقبال الإعلان وحفظه بحالة `pending`.
- عرض الإعلانات التي حالتها `published` فقط عبر `GET /api/listings`.

## مهم قبل النشر الحقيقي
هذه نسخة تجريبية وليست جاهزة للإطلاق العام:
1. لا توجد لوحة مشرف لمراجعة الإعلانات حتى الآن؛ لذلك الإعلانات الجديدة لا تظهر للعامة تلقائيًا.
2. لا توجد حسابات مستخدمين أو تحقق من ملكية رقم الهاتف.
3. لا تضع بيانات شخصية حقيقية أثناء التجربة.
4. ملف SQLite محلي، وقد تضيع البيانات عند استخدام استضافة لا تحفظ القرص. يجب اختيار استضافة وقاعدة بيانات دائمة قبل الإطلاق.
5. يلزم إضافة تحديد معدل الطلبات، حماية من الإساءة، سياسة خصوصية، وشروط استخدام قبل استقبال الجمهور.

## API التجريبية
- `GET /api/health` فحص حالة الخدمة.
- `GET /api/listings` الإعلانات المنشورة فقط.
- `POST /api/listings` إرسال إعلان للمراجعة.

أنواع التصنيف: `housing` و`jobs`. لا تستخدم بيانات سرية أو أرقام عملاء حقيقية في هذه النسخة.
