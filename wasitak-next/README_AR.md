# وسيطك Next — مشروع مستقل

هذه النسخة محفوظة في مجلد مستقل `wasitak-next/` وعلى فرع `wasitak-next`، ولا تستبدل ملفات تطبيق Flutter القديمة.

## التشغيل
1. استخدم Node.js إصدار 22.13 أو أحدث.
2. من مجلد `wasitak-next` شغّل `npm start`.
3. افتح `http://localhost:3000`.

## الحالة الحالية
هذه نقطة بداية تشغيلية لخادم Node وقاعدة SQLite محلية. قبل نشرها للجمهور يلزم إكمال المصادقة، مراجعة الإعلانات، رفع الصور، وسياسات حماية البيانات. لا تضع أسرارًا في ملفات الواجهة أو GitHub.

## نشر سحابي
يمكن فتح المستودع في GitHub Codespaces من المتصفح عبر https://github.com/codespaces ثم اختيار الفرع `wasitak-next`. Codespaces بيئة تطوير وليس استضافة دائمة للموقع.
