# وسيطك Next — موقع + API + تطبيق Expo

مشروع مستقل بهوية عربية RTL، مهيأ للتطوير المحلي. السيرفر يستخدم SQLite المدمج في Node.js.

## المتطلبات
- Node.js 22.13 أو أحدث.
- لتطبيق الموبايل: بيئة Expo SDK 54 المتوافقة.

## تشغيل الموقع والسيرفر
من مجلد المشروع:
```bash
ADMIN_EMAIL='admin@example.com' ADMIN_PASSWORD='ضع-كلمة-سر-قوية' npm start
```
افتح `http://localhost:3000` ولوحة الإدارة `/admin`. لا تستخدم بيانات مدير افتراضية ضعيفة.

## تشغيل تطبيق الموبايل
```bash
cd app
npm install
npx expo start
```
اضبط `EXPO_PUBLIC_API_URL` أو `app/src/config.js` على عنوان API الفعلي. لا تستخدم localhost على هاتف حقيقي.

## الوظائف
- تسجيل الحسابات وتسجيل الدخول.
- إعلانات العقارات والوظائف والباحثين عن عمل مع مراجعة إدارية.
- البحث والتصفية والتفاصيل وبيانات التواصل.
- رفع الصور وملفات PDF مع حدود للحجم.
- التقديم على الوظائف والسيرة الذاتية الاختيارية.
- لوحة إدارة للإعلانات والأعضاء وطلبات التقديم.
- حماية تنزيل السير الذاتية وإحصاءات الزيارات.

## اختبارات قبل النشر
```bash
npm test
npm run check
```
الاختبارات الآلية لا تغني عن تجربة تطبيق Expo على هاتف حقيقي.

## أمان ونشر
- لا ترفع ملفات الأسرار أو قاعدة البيانات أو ملفات المستخدمين إلى Git.
- اضبط أسرار المدير ومتغيرات البيئة على منصة الاستضافة.
- استخدم HTTPS وراجع سياسة الخصوصية والنسخ الاحتياطية.
- هذا المشروع يستخدم API ومخطط SQLite منفصلين؛ لا يرحّل بيانات Supabase القديمة تلقائيًا.
